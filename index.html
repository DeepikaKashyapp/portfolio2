Multimodal Product Inconsistency Detector

An AI catalog-auditing tool that uses OpenAI CLIP's dual-encoder to catch image–title mismatches in e-commerce listings.

  • Projects listings into a shared 512-d embedding space; cosine similarity with F1-optimised thresholding.
  • ~78% accuracy and 0.76 ROC-AUC on a 500-sample labeled test set.
  • Deployed as a live Streamlit app, tuned for low false-negative auditing.

EchoChat — Offline SOS Mesh Network

A 100% offline Android mesh network for emergency communication when the internet isn't an option.

  • BLE + Wi-Fi Direct multi-hop delivery across a 5-node chain, ~500m, zero internet dependency.
  • Custom Priority Triage Protocol (Levels 1–5) purges routine traffic at 80% buffer congestion for zero-latency SOS delivery.
  • libsodium end-to-end encryption with AODV routing, RSSI-based next-hop selection, TTL=5 loop prevention.
  • Android (Kotlin)
  • Bluetooth LE
  • Wi-Fi Direct
  • Nearby Connections API
  • SQLite
  • libsodium
