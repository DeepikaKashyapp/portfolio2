CodeTrack++

          
A competitive-programming platform with a browser IDE, personalised problem lists and a sandboxed code runner.

          

            
Problem
Leaderboard queries took ~320ms, and user-submitted JS/C++ can't be trusted to run on a server.

            
Built
A Monaco Editor IDE in React, a Node.js engine that runs submissions in sandboxed child processes against hidden tests, Redis Sorted Sets for ranking, and JWT auth.

            
Result
Leaderboard queries under 50ms, about 85% faster.

02 May 2026 · Solo

          
Multimodal Product Inconsistency Detector

          
An AI tool that audits e-commerce catalogs for listings where the photo and the title don't match.

          

            
Problem
Mismatched images and titles confuse shoppers, and checking listings by hand doesn't scale.

            
Built
OpenAI CLIP (ViT-B/32) maps images and titles into one 512-d space; cosine similarity with an F1-optimised threshold flags mismatches. Deployed on Streamlit.

            
Result
~78% accuracy and 0.76 ROC-AUC on a 500-sample labelled test set, tuned to miss as few mismatches as possible.

          

          
  • Python
  • CLIP
  • PyTorch
  • Scikit-learn
  • Streamlit

03 May 2026 · Solo

          
Zero-Waste Vision

          
Real-time waste sorting from a camera feed, built to run on ordinary hardware.

          

            
Problem
Sorting waste correctly needs real-time recognition, but most people don't have a GPU.

            
Built
YOLOv8n detection with MobileNet V2 classification, a mapping from 80+ object classes to disposal rules and carbon-savings estimates, and a Flask REST API behind a React frontend.

            
Result
162.1ms per frame (~6 FPS) on CPU. Showcased at Bharati Vidyapeeth's AI Solution Expo.

04 Jan 2026 · Team

          
EchoChat: Offline SOS Mesh Network

          
An Android mesh network for emergency messages when there's no internet at all.

          

            
Problem
In a disaster the internet is often the first thing to go, exactly when people need to send an SOS.

            
Built
Bluetooth LE + Wi-Fi Direct multi-hop delivery with AODV routing, RSSI-based next hops, TTL=5 loop prevention, and a Priority Triage Protocol that drops routine traffic at 80% buffer so SOS gets through.

            
My part
The frontend and product implementation, and the encryption & security layer: libsodium end-to-end encryption for messages and user data.

            
Result
Delivery across a 5-node chain (~500m) with zero internet.

          

          
  • Kotlin
  • Bluetooth LE
  • Wi-Fi Direct
  • Nearby Connections
  • SQLite
  • libsodium
